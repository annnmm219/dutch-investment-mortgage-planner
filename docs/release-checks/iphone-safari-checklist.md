# iPhone Safari checklist

Pass/fail on a physical iPhone in Safari. WebKit in CI is a proxy, not this check.

1. Open the preview link in Safari; the page loads and the not-advice note shows near the top.
2. Tap each tab (Investment, Mortgage, Scenarios); each one opens.
3. Tap a money field; a number keyboard appears.
4. Tap the notary transfer date; the iPhone date picker opens and keeps the date you pick.
5. Change that date from 2026 to 2027; the transfer tax updates straight away.
6. Change the mortgage amount; the result on that tab updates.
7. The chart on the Investment tab draws.
8. Turn the phone sideways and back; the page never scrolls sideways.
9. Export the CSV; the file opens from the share sheet.
10. Type a number, switch tabs and come back; the number is still there.
